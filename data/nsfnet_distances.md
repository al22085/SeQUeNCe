NSFNET distances (km)

- Source: SNDlib NSFNET topology (coords-based), distances computed via great-circle between published node locations; approximate values copied from prior studies using the same dataset.
- Units: kilometers along fiber (approximate).
- Columns: `u,v,distance_km` (undirected edges).

If you have more precise or updated NSFNET link lengths, replace `data/nsfnet_distances.csv` and pass `--edge-distance-csv` to overrides.
